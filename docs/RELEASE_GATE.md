# Release Gate: Private Research -> Public Code -> Zenodo

**Private stage:** maintain signed `codethor0` commits, private repository visibility, reproducible source/test files, explicit scope limits, and a confidential review record. No external publication occurs in this stage.

**Before any public disclosure:** obtain a qualified patent/IP review regarding inventorship, employment/assignment obligations, prior art, and filing strategy. Repository timestamps and author names support provenance but do **not** establish patent rights. No Zenodo publication or public GitHub release should be automatic.

**Public open-source stage (later):** select and review a license; remove secrets and confidential inputs; verify signers and citations; run tests and security checks; create an intentional signed release tag; archive that reviewed version on Zenodo and record its DOI in `CITATION.cff` only after issuance.

**Research claims:** distinguish a tested static reference kernel from the full time-dependent, delegated-authority RIFT hypothesis. No production-grade claims without an external-effect enforcement review.
